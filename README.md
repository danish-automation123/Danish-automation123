# Lead & Appointment Automation (GoHighLevel)

Two GoHighLevel workflows built for UNITZERO that handle leads coming from the LinkedIn profile and the UNITZERO website.

## The Problem
Leads from LinkedIn and the website had to be handled manually, which was slow and easy to miss.

## The Solution

### 1. New Lead Workflow
When a new lead comes in from LinkedIn or the UNITZERO website, it is added to the CRM automatically.

### 2. Appointment Booked Workflow
When a lead books an appointment, the workflow sends a confirmation and updates the contact automatically.

**Result:** leads no longer need to be handled manually.
